## UI and workflow review

The node move pane changes from **3 buttons + 1 select** to **2 buttons + 2 selects**. There is one Apply button and one clear/cancel button; the number of total form controls is still four. This is a simplification of competing edit actions and preview clarity, **not a measured reduction in height, retrieval time or total controls**. Disconnect hides the irrelevant destination selector; the full library omits the redundant action selector because only Attach is available there. Numeric prefixes follow the current graph index, with full destination titles retained. Native selected-record details are closed by default. Existing readable typography, wrapping, 44px minimum controls and focus styling remain; fresh narrow/short-height/keyboard/pixel acceptance is blocked.

The Apply accessible name starts with its visible caption and includes the explicit plan. The pane states that changes affect the working draft, need separate saving and do not accept evidence or record review. Previewing or clearing a selection does not request authority or change a case. Cancel invalidates an awaiting operation before any apply, gives a visible status and returns to the scoped search control. Its DOM calls are modeled in tests; live focus/scroll remains unverified. Completed selections also invalidate captured write callbacks immediately. Conflicting destination links are refused by the existing handler; no rule carriers are merged or dropped. Evidence retained after node deletion can be selected in the library and reattached through the same preview. Full text remains available and reference/missing-only records do not gain edit or download privileges.

The download boundary uses the same operation/context fence. Synthetic sink checks verify in-scope literal text and actual local ZIP bytes; stale node/locale/source/access contexts deliver no file to the sink. This does **not** prove real browser downloads or sealed JSON/PDF acceptance. Read-only material inspection remains independent of copy/export permission.
