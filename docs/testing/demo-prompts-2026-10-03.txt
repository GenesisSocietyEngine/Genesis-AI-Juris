CASE STUDIO — ILLUSTRATIVE DEMO PROMPTS
Reviewed 3 October 2026

Outcome and acceptance
Each of the nine registered categories has a concise, meaningful English and
Russian task prompt. A card previews the same text installed in the editable
Studio brief. Loading is explicit; it does not run AI, promote instructions to
facts, alter the authored evidence packet or certify an output. Cancelled,
failed, stale or refused launches must preserve existing work.

Implementation
Nine prompts cover Harbor, Northline, Cloudbridge, Orchard, Clearpath, Meridian,
Atlas, Beacon and Signal. Each states a fictional situation, a task and an
evidence/review constraint. Professional routes remain conditional; the training
prompt asks the learner to choose and explain a route instead of prescribing it.
The existing question remains the decision-map trigger. Prompts remain separate
from draft premise/evidence and are editable through Brief & structure > Edit
the brief (RU: Задача и структура > Изменить описание).
The catalogue card replaces its previous question paragraph with a labelled
prompt preview; no additional tile, badge, banner or nested disclosure is added.
What to explore explains the edit path and explicit AI behavior.
Template examples use the same guarded launch. Empty templates retain their
intake questions. The Canopy walkthrough and published simulations retain their
existing authored scenario summaries/player instructions; this slice adds
editable prompts to the nine category teaching drafts.

Review and corrections
The first implementation exceeded the unchanged 325,000-byte Studio entry
budget (325,526 bytes). Prompt data and worked-example cards now load through
deferred modules. The rebuilt entry is 314,516 bytes; the original budget test
passes. No package dependency or network generation was introduced.
The prompt and draft load together before the existing latest-request/context/
identity check and confirmed replacement. Prompt changes occur only after a
successful replacement; asynchronous losers cannot clear or install a brief.
The RU navigation label was checked against the actual control wording.
Static React content uses stable category keys and existing paragraph/disclosure
styles. No new effects, subscriptions or per-render case serialization were added.
