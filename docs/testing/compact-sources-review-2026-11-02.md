## Design and preservation review

- One native disclosure per material exposes full text and related-node controls together. Title, complete status note, related-node count and the separate file download stay visible while collapsed. Related-node counts describe the existing material projection, including its own evidence record where applicable; they are not edge counts, coverage or review.
- Search passage snippets remain visible outside the collapsed body. Opening a match retains literal text and focus. Returning from a node opens all containing disclosures before restoring the original control. The queued disclosure event does not steal that restored node-control focus.
- Per-file downloads remain one action outside the disclosure. Archive/download authority and evidence batch handlers are unchanged. Select controls remain separate from row expansion; narrow layouts give the title its own full-width space. Native keyboard disclosure behavior, focus outlines, complete long titles and EN/RU labels remain.
- Reference rows align the working record, exact document/version/section and source-opening action. Missing-reference and verbatim-mismatch warnings remain present. Retained packet/history, source return, unaccepted working-record status and all original-file limits are preserved.
