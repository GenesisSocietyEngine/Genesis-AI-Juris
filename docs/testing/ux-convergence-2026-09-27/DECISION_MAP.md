Intended outcome: understand the entire decision route, then inspect readable details without changing the working model merely by changing the view.

Acceptance: Fit contains both width and height; Detail returns to readable scale; List exposes every node and connected destination with recorded reasoning; keyboard selection opens the same inspector; no node, source or approval is fabricated. Changed semantic input invalidates the prepared recommendation (covered separately by Overview). Existing editing/undo and reports remain intact. Browser checks and regression results are recorded after implementation.
