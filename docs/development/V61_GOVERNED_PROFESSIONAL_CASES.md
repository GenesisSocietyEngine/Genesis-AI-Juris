# v61 — Governed professional case packages

This release combines the v60 governance boundary with the v61 case-package expansion.

- Nine immutable case types share one versioned registry and one playbook contract.
- Litigation, contract review, tax planning, compliance, and investigation join the four v59 packages.
- Flutter reads the same byte-identical registry and playbook assets as the shared contracts.
- Unknown IDs and versions continue to fail closed before draft persistence.
- Only training simulations require a playable Rust route; all packages still pass authoritative Rust schema validation.
- Mobile version: 0.11.0+18.

External report governance remains a web authoring concern; mobile preserves the pinned case identity and canonical validation boundary without introducing a second rules engine.
