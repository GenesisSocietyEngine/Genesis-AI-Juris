# CaseVant: the current workflow

Updated 3 November 2026 · 4:00 · English synthetic narration · no subtitles

Narrated workflow illustrations; not a screen recording or authenticated acceptance demonstration. No subtitles or burned-in narration.

## 0:00 — Start with an independent case

Browse example cases and choose one of nine case categories. Topics and jurisdictions are separate filters. Open example case creates an independent working draft. You can also create a blank case, choose a template, or import a file. Keep existing work before replacing a draft. Project Canopy follows the same opening flow as other examples.

## 0:30 — Describe and review before applying

Describe the decision, your role, jurisdiction, deadline, known facts and desired outcome. Review proposed changes before applying them. Review without AI is a conditional local fallback; if it is not offered, edit manually in Decision. A complete canonical Markdown file uses Verify canonical case, then Apply exact case. An ordinary prompt is not exact restoration.

## 1:00 — Read the exact source

In Sources and evidence, search loaded titles, notes and text. Expand a document to read its full body and related nodes. A node can open its cited document version and section directly. Check missing, changed and hypothetical material before relying on it. Missing originals have no invented file. Text references and working records are not automatically accepted evidence.

## 1:30 — Work with the decision map

Use Decision to inspect the map or its list view. Find a node by its prefix or title. Click a type in the left Add node palette, or drag it onto the map. Zoom changes in ten percent steps. Manual placement, connections and edits belong to the working draft. Use Undo or Redo to inspect changes before saving. Hypothetical outcomes remain scenarios.

## 2:00 — Preview evidence changes

Select working records. Choose Attach, Move, or Disconnect. Check the count and exact destination, then Apply change. Cancel stops a pending change while access is checked. Switching case, node, language or access clears the old intent. Text stays in the library. Save separately; rearranging records does not accept or review evidence.

## 2:30 — Follow a finding and return

In Review, the number to review opens completeness checks and their actions. These checks do not establish reliability or professional approval. Open a finding, inspect its node and read the cited passage when available. Use Back to review finding to return. A resolved finding or changed source context may clear that return. Keep assumptions, missing support and conditional findings explicit.

## 3:00 — Save, confirm and reopen

Use Save in the header. Sign in with the intended account and complete the requested profile if necessary. Wait for Saved to workspace. Reopen the saved version from My cases, Personal, and inspect its content in another tab. Keep the original tab until verified. Further edits need another confirmed save. A save conflict preserves your edits; do not overwrite another version blindly.

## 3:30 — Inspect exports and preserve recovery

Choose Base, Medium or Full analysis in Reports. Preview, download and open the actual PDF. Full analysis deliberately retains the complete record; it is not the default Base report. Case JSON requires saved-version and access checks. Preserve original files for recovery, including unsupported historical versions. Saving and exporting do not grant professional approval.
