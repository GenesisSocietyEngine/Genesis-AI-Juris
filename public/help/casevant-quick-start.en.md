# CaseVant — current quick start

Updated: 2026-11-02

## 1. Start with a brief, template or file

In Case Studio, describe the decision, your role, jurisdiction, deadline, known facts and desired outcome. Templates start a fresh draft with intake questions; Demo contains fictional examples. Before replacing current work, preserve it. For an ordinary brief, use Import case or prompt and review the proposed structure before applying it.

## 2. Restore an exact case file

For a complete canonical Markdown export, choose Verify canonical case, inspect the preview, then Apply exact case. Keep the entire file, including its embedded data. A normal prompt is not an exact restoration. Import opens a draft; it does not confirm a workspace save.

## 3. Review the structure and evidence

Give the case a clear title. Use Overview → Sources & evidence → Decision → Review → Reports. Open Brief & structure to edit the brief or review proposed changes. Check proposed facts, alternatives and outcomes before accepting them. Separate verified evidence, estimates and missing information. The Next step card helps you continue; it is not a review or approval.

## 4. Save, wait for confirmation, then reopen

Use Save to workspace. Sign in and complete your profile if prompted. Wait for Saved to workspace, then open My cases → Personal with the same account and check the saved content in a separate tab. Further edits need another confirmed save. Keep the original tab until you have verified the saved copy.

## 5. Find personal and team work

Personal contains your account-owned Studio cases. Team contains governed organization records: select the correct organization and permissions. Importing or saving a personal draft does not create a Team record. A browser draft or downloaded case file is stored separately from both collections.

## 6. Inspect the actual report

Choose Create analytical report, then Preview PDF or Download PDF. Open the downloaded file and check the title, facts, evidence, alternatives and unresolved conditions. A download-started message does not confirm receipt. Saving, file verification and PDF export do not independently approve a decision.

## Questions and recovery

### Where are my cases after moving to casevant.pro?

Sign in again with the same account and open My cases → Personal. For Team, select the same organization. Sessions and device-only drafts belong to the earlier domain. Keep that tab in the same browser/profile, save there and wait for confirmation, or use a permitted export. Follow the recovery instructions below before closing the original.

### Do I need AI to create or edit a case?

You can enter and review the case manually. AI-assisted preparation requires the account, completed profile and service access requested by the interface. If it is unavailable, keep your brief and continue with manual editing. Review any proposed structure before applying it.

### Are Demo and Templates duplicates?

Demo contains fictional walkthroughs and decision simulations. Templates create a fresh Studio draft with a case type and intake questions; they do not copy a demo's facts, documents or conclusions.

### Why does canonical verification fail?

Use the complete exported Markdown file, not copied visible text. If embedded data or the fingerprint is missing or mismatched, obtain an intact export. Do not treat ordinary text as an exact restoration.

### What if sign-in or saving is unavailable?

Keep the current tab and a permitted export. Use Account on the published site. If the page fails, report its address, time and displayed error without sending credentials or private evidence. Opening another domain does not transfer an unsaved draft.

### What if saving times out?

Keep the original tab. Open Personal cases separately and inspect the most recent saved content before retrying: an uncertain response does not prove the write failed. Preserve a permitted export; report the case reference, operation and displayed error if the result remains uncertain.

### What if the PDF does not appear?

Check the browser's downloads and popup settings, then try Preview PDF. Open the actual file to confirm it arrived. Keep the case open and report the displayed error if it persists.

It combines a real CaseVant opening screen with labeled workflow illustrations. Account saves, AI and Team creation are instructions, not recordings of completed actions. Check the inputs in your own case.

Open Help & training → Scenario recordings. Two short videos show source inspection/return and local review/edit/apply/Undo/Redo. They use actual browser step captures from an isolated local preview with fictional/synthetic data, not continuous footage or authenticated save/AI/download acceptance. EN/RU captions and transcripts are available.

Review without AI is shown when AI is unavailable or has failed. If absent, edit the map manually in Decision; canonical imports use the exact-file flow. Use the local review to inspect the complete local proposal before Apply; Edit brief preserves your input. Context-only proposals add text without records. In Sources & evidence, search loaded document text and use Open exact reference passage → Back to citing record for the precise version/section and return focus. Missing originals remain unavailable. These actions do not accept evidence, approve a decision or confirm a workspace save.
