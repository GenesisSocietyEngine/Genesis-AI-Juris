# CaseVant — current quick start

Updated: 2026-11-03

## 1. Start with a brief, template or file

Create a case, choose a template or browse example cases. The library uses nine case categories; topics and jurisdictions are separate filters. Open example case starts an independent working draft. Describe your decision, role, jurisdiction, deadline, facts and desired outcome. Preserve existing work before importing or replacing a draft.

## 2. Review local changes without AI

Review without AI appears when AI is unavailable or has failed. If it is not shown, use Decision to edit the map manually; canonical files use the exact-file flow below. Enter your brief, choose the local review and read the complete proposal, use Edit brief to revise it, then Apply these changes. A context-only proposal adds text without creating records. The optional starter map is under Other local options. Undo and Redo affect the working draft; they do not confirm a workspace save or professional approval.

## 3. Find a passage and return to its reference

In Sources & evidence, search loaded titles, notes and text. Expand a document to read its body and related nodes. In a node, Cited passages opens its exact retained document/version/section; check the source-version and mismatch notices. Use Back to review finding when available. The full Sources panel also offers Open exact reference passage and Back to citing record. Missing originals have no body or file; reading a source does not accept evidence.

## 4. Restore an exact case file

For a complete canonical Markdown export, choose Verify canonical case, inspect the preview, then Apply exact case. Keep the entire file, including its embedded data. A normal prompt is not an exact restoration. Import opens a draft; it does not confirm a workspace save.

## 5. Preview evidence changes and cancel

Select working records. Choose Attach, Move, or Disconnect. Check the count and exact destination, then Apply change. Cancel stops a pending change while access is checked. Switching case, node, language or access clears the old intent. Text stays in the library. Save separately; rearranging records does not accept or review evidence.

## 6. Review the structure and evidence

Use Overview → Sources & evidence → Decision → Review → Reports. Brief & structure edits the brief or proposed structure. Help with this step keeps optional guidance compact. Review and the count to review open completeness actions, not professional approval. Check assumptions, hypotheses, missing support and conditional findings. Return from a cited passage through the provided finding action.

## 7. Save, wait for confirmation, then reopen

Use Save in the header. Sign in with the intended account and complete the requested profile if necessary. Wait for Saved to workspace. Reopen the saved version from My cases, Personal, and inspect its content in another tab. Keep the original tab until verified. Further edits need another confirmed save. A save conflict preserves your edits; do not overwrite another version blindly.

## 8. Find personal and team work

Personal contains your account-owned Studio cases. Team contains governed organization records: select the correct organization and permissions. Importing or saving a personal draft does not create a Team record. A browser draft or downloaded case file is stored separately from both collections.

## 9. Inspect the actual report

Choose Base, Medium or Full analysis in Reports. Preview, download and open the actual PDF. Full analysis deliberately retains the complete record; it is not the default Base report. Case JSON requires saved-version and access checks. Preserve original files for recovery, including unsupported historical versions. Saving and exporting do not grant professional approval. Export case brief (.md) offers Working brief and Prepared brief; Prepared brief does not record human review or approval.
